security Security Policies (RLS)

Profile Isolation

Children can only SELECT and UPDATE their own profile record where auth.uid() = id.

Parental Oversight

Parents/Tutors can SELECT progress_logs for any child_id linked in tutor_settings.

rule Progression Rules

1

User completes a module attempt. A record is inserted or updated in progress_logs.

2

System checks repetition_count. If count ≥ 3 and score > 80%, trigger mastery.

3

is_mastered is set to TRUE, unlocking the next level in profiles.

Logic Hook

CREATE TRIGGER on_mastery AFTER UPDATE ON progress_logs FOR EACH ROW EXECUTE FUNCTION update_user_level();
